# Tree-Canopy-Detection
Detecting tree canopies across multiple resolutions of aerial and satellite imagery

## Competition Submission Form

This repository includes a web-based submission form for participants to submit their predictions and model information for the Tree Canopy Detection Competition.

### Quick Start

1. Clone this repository
2. Start a local web server (e.g., `python3 -m http.server 8080`)
3. Open `http://localhost:8080` in your browser
4. Fill out the form and submit your predictions

For detailed instructions, see [SUBMISSION_GUIDE.md](SUBMISSION_GUIDE.md).

### Features

- ✅ User-friendly web interface
- ✅ Form validation for all inputs
- ✅ CSV file upload for predictions
- ✅ Team and solo participation support
- ✅ Model metadata collection
- ✅ Responsive design for mobile and desktop

### Files

- `index.html` - Main submission form
- `styles.css` - Form styling
- `script.js` - Form validation and submission logic
- `SUBMISSION_GUIDE.md` - Detailed usage instructions
